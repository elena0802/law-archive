# Feedback Log

## Purpose

Track **qualitative feedback** separately from GA4, Clarity, and custom events. Analytics show *what* happened; this log captures *what people said*, *what they asked for*, and *how they reacted* in their own words or through observable behavior.

Pair with `docs/product-learning-log.md` (learnings) and `docs/decision-log.md` (choices). Add a new entry when feedback arrives—do not rewrite old entries.

### Entry format

| Field | Notes |
|-------|--------|
| **Date** | YYYY-MM-DD (when feedback was received or observed) |
| **Source** | Professor, visitor, peer, channel (e.g. 단톡방, email, guestbook) |
| **Feedback** | Quote or concise paraphrase; mark direct quotes with quotation marks |
| **Type** | Request · Praise · Confusion · Objection · Idea · Behavioral signal |
| **Possible Action** | None · Monitor · Discuss · Backlog · Decide (link to decision log if acted on) |
