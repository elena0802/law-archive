# Weekly Metrics

## Purpose

Record **key product metrics once per week** in one place. Use GA4 and Clarity for traffic and engagement; use GA4 custom events and admin for community activity. Compare week-over-week and against targets in `docs/analytics-dashboard.md`.

**Cadence:** Monday morning, previous calendar week (Mon–Sun).  
**Scope:** Public site only (admin CMS excluded from analytics).

### Where to read each metric

| Metric | Source |
|--------|--------|
| Users, Sessions, Engaged sessions, Avg. engagement time, Views / session | GA4 → Reports → Engagement (or Home), date range = week |
| Research page views | GA4 → Pages: `/research`, `/research/*` view count |
| Guestbook entries | GA4 event `guestbook_created` **or** admin guestbook new entries |
| Comments | GA4 event `comment_created` |
| Newsletter subscribers | GA4 event `newsletter_subscribed` (new subs that week) |
| Search usage | GA4 event `search_used` |
